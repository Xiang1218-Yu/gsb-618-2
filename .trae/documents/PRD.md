# 青旅民宿床位预订管理系统 - 产品需求文档

## 1. 产品概述
面向小型青旅/民宿的床位级在线预订与管理系统，提供直观的床位选择、智能拼房匹配、性别偏好筛选功能，无需后端服务，使用本地存储实现数据持久化。
- 解决小型住宿经营者床位管理混乱、拼房匹配困难、入住名单统计繁琐的问题
- 目标用户：青旅客栈经营者、民宿管理员、预订旅客
- 核心价值：床位可视化管理、自动拼房匹配、实时入住名单、零成本部署

## 2. 核心功能

### 2.1 用户角色
| 角色 | 访问方式 | 核心权限 |
|------|----------|----------|
| 旅客用户 | 直接访问预订页面 | 浏览房间、选择床位、提交预订、性别偏好设置 |
| 管理员 | 切换到管理视图 | 查看所有预订、管理房间床位、查看入住名单、删除预订 |

### 2.2 功能模块
1. **预订大厅**：房间展示、床位选择、预订表单
2. **管理后台**：房间管理、入住名单、统计概览
3. **智能拼房**：性别偏好匹配、混住规则、床位推荐

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 预订大厅 | 顶部导航 | 品牌Logo、旅客/管理员视图切换、日期选择 |
| 预订大厅 | 房间列表 | 展示所有房间卡片、房间类型、剩余床位数量、价格 |
| 预订大厅 | 床位平面图 | 可视化床位布局、可用/已订/选中状态标识、性别标签 |
| 预订大厅 | 预订表单 | 姓名、性别、入住日期、离店日期、联系方式、性别偏好 |
| 预订大厅 | 智能推荐 | 根据性别偏好自动推荐合适床位 |
| 管理后台 | 统计仪表盘 | 今日入住、总预订数、床位利用率、房间状态概览 |

## 3. 核心流程

### 旅客预订流程
1. 用户进入预订大厅，查看可用房间列表
2. 选择入住日期和离店日期
3. 点击房间查看床位平面图
4. 设置性别偏好（仅男/仅女/混住均可）
5. 系统高亮推荐符合偏好的可用床位
6. 用户选择一个或多个床位
7. 填写入住人信息（姓名、性别、联系方式）
8. 确认提交预订
9. 系统更新床位状态并保存到本地存储

### 管理员管理流程
1. 切换到管理后台视图
2. 查看统计数据和房间状态
3. 管理房间配置（添加、修改床位数）
4. 查看实时入住名单
5. 处理取消预订
6. 系统自动更新床位可用状态

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖木质色调（#8B5A2B 深木色、#D2B48C 浅木色）搭配清新青旅绿（#2E8B57）
- **辅助色**：柔和米色（#F5F5DC）背景、珊瑚橙（#FF7F50）作为强调色
- **按钮风格**：圆角微立体、悬停时有微妙阴影变化、点击有按压反馈
- **字体选择**：标题使用 Noto Serif SC（优雅衬线），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：卡片式布局、适度留白、温暖的民宿氛围、床位采用上下铺图标可视化
- **图标风格**：Lucide 线性图标，配合少量emoji增加亲切感（🛏️ 🚻 🏠）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 预订大厅 | 顶部导航 | 木质渐变导航栏、毛玻璃效果、平滑过渡动画 |
| 预订大厅 | 房间卡片 | 圆角卡片、悬停上浮效果、剩余床位进度条、房型标签 |
| 预订大厅 | 床位布局 | 上下铺可视化、不同颜色区分性别、选中动画效果 |
| 预订大厅 | 预订表单 | 分步引导表单、输入框聚焦发光效果、确认按钮动效 |
| 管理后台 | 统计卡片 | 渐变背景卡片、数字计数动画、趋势图标 |
| 管理后台 | 入住名单 | 表格布局、行悬停高亮、状态标签、快速筛选 |

### 4.3 响应式设计
- 桌面优先设计，适配平板和手机端
- 床位平面图在移动端采用垂直滚动布局
- 管理后台表格在移动端转为卡片式列表
- 触摸优化：按钮尺寸≥44px，手势友好

### 4.4 动效设计
- 页面加载：渐入动画，元素依次显现
- 床位选择：点击缩放反馈，颜色平滑过渡
- 表单提交：加载状态动画，成功提示动效
- 数据更新：数字滚动效果，状态变化平滑过渡
