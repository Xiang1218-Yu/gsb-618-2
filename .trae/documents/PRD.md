# 青旅/民宿床位预订管理系统 - 产品需求文档

## 1. 产品概述
小型青旅/民宿床位级在线预订管理系统，支持可视化床位选择、多人混住拼房自动匹配、性别偏好筛选，实时展示剩余床位与入住名单，纯前端本地运行无需后端服务。
- 目标用户：青旅/民宿经营者与住客
- 核心价值：降低拼房管理成本，提升预订体验与入住效率

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 住客 | 前台浏览预订 | 查看房间床位、提交预订、选择性别偏好 |
| 管理员 | 管理面板入口 | 查看入住名单、管理房间床位配置、处理预订 |

### 2.2 功能模块
1. **预订页面**：房间概览、床位可视化选择、性别偏好筛选、预订表单
2. **管理页面**：实时入住名单、房间状态总览、预订管理、房间配置

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 预订页面 | 房间列表展示 | 展示所有房间（多人间、单人间），显示房型、床位数、价格、剩余床位 |
| 预订页面 | 床位可视化 | 俯视图形式展示每个房间的床位布局，不同颜色区分：空床/已预订/已入住/自己选中 |
| 预订页面 | 性别偏好筛选 | 住客可选：仅女性房间/仅男性房间/不限，系统自动过滤可拼房床位 |
| 预订页面 | 拼房匹配提示 | 选中床位时提示当前房间已入住人员性别构成，辅助决策 |
| 预订页面 | 预订表单 | 填写姓名、性别、联系电话、入住日期、退房日期 |
| 预订页面 | 预订确认 | 提交后锁定床位，显示预订成功信息 |
| 管理页面 | 入住名单总览 | 按日期展示所有预订记录，支持搜索筛选 |
| 管理页面 | 房间状态看板 | 实时显示每个房间的床位占用率、入住人员明细 |
| 管理页面 | 房间配置 | 添加/编辑房间，设置房间类型、床位数、性别限制 |
| 管理页面 | 预订操作 | 确认入住、取消预订、修改状态 |

## 3. 核心流程

### 住客预订流程
住客进入系统 → 浏览可用房间 → 选择性别偏好过滤 → 点击房间查看床位详情 → 选择空床位 → 填写个人信息 → 提交预订 → 系统自动校验拼房匹配 → 预订成功 → 床位状态更新

### 管理员管理流程
管理员进入管理面板 → 查看当日入住名单 → 办理入住/取消预订 → 查看房间实时状态 → 配置房间与床位

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖的青旅风格——暖橙色(#E86A33)作为主色，搭配深青色(#1A3C40)作为辅色，米白色(#FAF6F0)为背景
- **按钮风格**：圆角卡片式，微阴影，hover时有轻微上浮效果
- **字体**：标题使用 Noto Serif SC（衬线体增加温馨感），正文使用 Noto Sans SC
- **布局风格**：卡片式布局，顶部导航切换「预订」与「管理」，床位使用圆形/方形图标
- **图标风格**：Lucide 线性图标，简洁现代

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 预订页面 | 顶部导航 | 品牌Logo + 预订/管理切换Tab，固定顶部 |
| 预订页面 | 筛选栏 | 性别偏好切换按钮组（全部/女/男），日期选择器 |
| 预订页面 | 房间卡片 | 卡片式展示房间照片/图标、名称、房型标签、价格、剩余床位进度条 |
| 预订页面 | 床位布局图 | 房间俯视图，床位用圆形表示，颜色编码状态：绿色=空床、橙色=选中、蓝色=已订女性、深蓝色=已订男性、灰色=已入住 |
| 预订页面 | 预订弹窗 | 模态框表单，输入姓名、性别选择、电话、日期范围 |
| 管理页面 | 数据概览 | 顶部统计卡片：总房间数、今日入住、今日退房、入住率 |
| 管理页面 | 入住名单表 | 表格形式展示预订记录，每行含状态标签与操作按钮 |
| 管理页面 | 房间状态看板 | 网格布局展示各房间实时床位占用情况 |

### 4.3 响应式设计
- 桌面优先，适配平板与手机
- 手机端房间卡片单列布局，床位图自适应缩放
- 管理页面表格在小屏幕上转为卡片视图
