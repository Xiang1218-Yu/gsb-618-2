# 青旅/民宿床位级在线预订管理系统 - 产品需求文档

## 1. 产品概述
面向小型青旅/民宿的床位级预订管理系统，支持可视化床位选择、智能拼房匹配与性别偏好筛选。目标用户为青旅客栈经营者与住客，解决多人间床位分配与拼房管理问题，实现纯前端本地存储即可运行。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 住客用户 | 无需注册 | 浏览房型、选择床位、提交预订、选择性别偏好 |
| 管理端 | 无需登录 | 查看实时入住名单、管理房间床位、查看预订记录 |

### 2.2 功能模块
1. **首页/预订页面**：房型展示、日期选择、床位可视化选择、性别偏好筛选
2. **管理后台**：实时入住名单、房间状态总览、预订记录管理

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页预订页 | 头部导航 | 品牌标识、切换到管理端入口 |
| 首页预订页 | 日期选择器 | 选择入住日期和离店日期，计算天数 |
| 首页预订页 | 房型列表 | 展示各房间类型（4人/6人/8人间等）、价格、剩余床位动态显示 |
| 首页预订页 | 床位平面图 | 可视化展示房间床位布局，实时标记已订/可选/自己选中状态 |
| 首页预订页 | 性别偏好筛选 | 女生房/男生房/混住选项，智能匹配同房已住客人性别 |
| 首页预订页 | 预订表单 | 填写姓名、性别、联系电话、特殊要求 |
| 首页预订页 | 拼房匹配提示 | 自动显示当前选中房间已住客人性别构成，提示拼房情况 |
| 首页预订页 | 提交预订 | 验证床位可用性、保存订单到 localStorage |
| 管理后台 | 头部导航 | 返回预订页入口、数据统计摘要 |
| 管理后台 | 房间状态总览 | 各房间入住率卡片、实时剩余床位数 |
| 管理后台 | 入住名单列表 | 按房间分组显示当前入住客人名单、性别标记、入住日期 |
| 管理后台 | 预订记录 | 所有历史预订记录查询、取消预订功能 |
| 管理后台 | 房间编辑 | 初始化房间房型配置（床位数、房间名称、价格） |

## 3. 核心流程
1. **预订流程**：用户进入首页 → 选择入住离店日期 → 浏览房型筛选性别偏好 → 点击房间查看床位图 → 点击可选床位选中 → 填写预订人信息 → 提交预订 → 系统保存并显示预订成功
2. **管理流程**：管理员进入后台 → 查看实时房间入住状态 → 查看各房间入住名单 → 可取消预订/编辑房间配置

## 4. 用户界面设计
### 4.1 设计风格
- **主色调**：温暖的青旅旅行感 - 青绿色(#0d9488)为主色，搭配暖橙色(#f97316)作为强调色
- **辅助色**：米白色背景(#fefce8)、深灰色文字(#1f2937)
- **床位状态色**：可用-淡绿(#86efac)、已订-淡红(#fca5a5)、选中-橙色(#fb923c)
- **按钮风格**：圆角微立体，hover时有轻微上浮阴影效果
- **字体**：中文用 Noto Sans SC，标题加粗，数字用等宽字体
- **布局**：卡片式布局，清晰的分区，充足留白
- **图标风格**：Lucide 线性图标，简洁现代

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页预订页 | 头部 | 青绿色背景栏，品牌名+🏠图标，管理端入口按钮 |
| 首页预订页 | 日期选择 | 双日期选择器，显示"共X晚"，圆角输入框 |
| 首页预订页 | 房型卡片 | 悬浮阴影卡片，显示房间名、床型图、价格/晚、剩余X床标签 |
| 首页预订页 | 床位平面图 | 类似宿舍上下铺布局，床位方块点击态过渡动画 |
| 首页预订页 | 性别筛选 | 三个分段按钮：女生房/男生房/混住，选中态高亮 |
| 首页预订页 | 预订弹窗 | 居中模态框，半透明遮罩，表单标签清晰 |
| 管理后台 | 统计卡片 | 横向三卡片：总房间、今日入住、预订总数 |
| 管理后台 | 入住名单 | 按房间分组，头像+姓名+性别符号+日期，时间轴样式 |
| 管理后台 | 房间编辑 | 简单表单添加/编辑房间 |

### 4.3 响应式设计
- 桌面优先设计
- 平板适配：两列布局改为一列
- 移动端适配：床位图自适应缩放，表单全宽
- 触摸优化：按钮触摸区域≥44px
